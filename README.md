# Portafolio web — Lisbeth Cedeño

Sitio personal de una página, con diseño azul, adaptable a móviles y sin dependencias externas. Incluye presentación, proyectos académicos, competencias, certificados, experiencia, LinkedIn, correo y CV descargable.

## Verlo en tu computadora

Abre `index.html` con el navegador. También puedes usar un servidor local desde la carpeta:

```bash
python -m http.server 8000
```

Visita `http://localhost:8000`.

## Publicarlo gratis en GitHub Pages

1. Crea un repositorio público, por ejemplo `portafolio`.
2. Sube los archivos **conservando** `index.html`, `styles.css`, `script.js` y la carpeta `assets/`.
3. En el repositorio abre **Settings → Pages**.
4. Selecciona **Deploy from a branch**, rama `main`, carpeta `/ (root)`.
5. La página quedará disponible en `https://TU-USUARIO.github.io/portafolio/` una vez finalizado el despliegue.

## Personalizar

- Información y enlaces: `index.html`.
- Colores y distribución: `styles.css`.
- Filtros y menú: `script.js`.
- CV: reemplaza `assets/CV_Lisbeth_Cedeno.pdf` por una versión actualizada con el mismo nombre.
- Fotografía: actualmente se utiliza una ilustración abstracta, no una foto personal.
